### Explore uma demonstração: visão computacional

O projeto de imagens industriais permite acompanhar uma sequência de processamento, examinar as decisões de implementação e executar testes com entradas de exemplo.

- [Código do pipeline](https://github.com/fernandababeto-byte/mini-projeto-visao-computacional/blob/main/preprocess.py)
- [Comparativo visual das etapas](https://github.com/fernandababeto-byte/mini-projeto-visao-computacional/blob/main/docs/comparativo_pipeline.jpg)
- [Testes automatizados](https://github.com/fernandababeto-byte/mini-projeto-visao-computacional/blob/main/tests/test_pipeline.py)
- [Relatório original de validação](https://github.com/fernandababeto-byte/mini-projeto-visao-computacional/blob/main/docs/relatorio_validacao.md)

Após instalar as dependências conforme o README desse projeto, execute na pasta dele:

```bash
python -m unittest discover -s tests -v
```

A revisão de 24/10/2026 registrou cinco testes aprovados com Python 3.12, NumPy 1.26.4 e OpenCV Headless 4.10.0.84. O relatório original registra 1.300 imagens processadas; esse lote não foi repetido na revisão. Esses registros não são medidas de acurácia na detecção de defeitos.

## Direção de pesquisa

**Linha provisória: Sistemas Inteligentes e Agênticos para Geração, Recuperação e Otimização de Valor Econômico.**

Quero investigar como IA generativa, aprendizado de máquina, agentes, PLN, recomendação, automação e otimização podem contribuir para decisões economicamente úteis e confiáveis.

Perguntas que orientam essa direção:

- Como medir o benefício de uma solução frente a uma alternativa simples ou ao processo atual?
- Quando a automação reduz custos e quando apenas transfere trabalho para revisão humana?
- Como equilibrar qualidade, custo de operação, confiabilidade e supervisão?
- Quais problemas são recorrentes e relevantes a ponto de sustentar o uso contínuo de uma solução?

O tema científico definitivo ainda está em avaliação. As perguntas acima são direções de investigação, não resultados científicos ou alegações de originalidade.
